§1现状诊断：为什么"不直观、很难配置"

症状根因（对应现有实现）
配置时"看不见全局"一切都挤在一个 3xl 模态框里（WorkflowEditor.tsx）：触发器表单 + N 个节点表单纵向排队，配置第 3 个节点时链条其余部分全部滚出视野。
读不出"流程"感链条被渲染成纵向卡片堆叠（ActivityCard 列表），节点之间的类型标签（ItemTypePill）又小又淡——用户看到的是"一摞设置卡"，不是"一条流水线"。
配置一个节点，页面跳一下表单藏在卡片的手风琴里，展开/收起把下方所有卡片推来推去，位置感全失。
不知道"还能加什么"可用节点藏在"添加活动"弹出的选择器（ActivityPicker）里，能力完全不可见；类型不兼容的节点直接消失，用户不知道它们存在、更不知道为什么不能用。
拖拽没有"节点"手感dnd-kit 的列表排序：能拖，但只是"换行序"，没有插槽、没有吸附、没有让位动画。

§2方案：三栏画布，模态换全屏

区域职责关键决定
顶栏名称、启用开关、保存 / 运行 / 运行记录、校验提示软校验（如"链上没有动作"）以提示条出现，不阻塞编辑；硬校验（类型断链）阻止保存并在画布上标红断点。
左栏 · 节点库全部节点按域分组常驻可见，顶部搜索接不住当前链尾类型的节点变暗但不隐藏，悬停给出原因（"此节点接受订阅条目，当前流动的是文件系统条目"）——能力可发现，约束可理解。可经 AI 桥接的节点保留原有"需 AI 桥接"标记。
中央 · 画布链条 = 横向节点流：触发器 → 节点… → 终点摘要连线上标条目类型与 1→N 展开；拖动时插槽磁性吸附（阈值内链条让位张开、插槽发光）；节点可拖动换位、拖离链条移除；点选节点在右栏配置。触发器是特殊首节点：不可拖除，点它配置触发器与过滤。
右栏 · 检查器被选节点的配置表单 + 错误策略 + 帮助入口表单固定在右栏，链条永远可见、永不跳动；表单组件与现在完全同一套（ConfigForm/FilterForm 原样复用），杜绝双实现漂移——与 RenamePlanPanel 的"同一组件双形态"同一条纪律。
承载方式建议：路由页（/workflow/editor/:id?），列表页保留现状。全屏模态也可行，但路由页可直达、可刷新、可放进浏览器历史，与 file-processor 等既有全屏页一致。窄屏（<900px）画布退化为纵向流，三栏变上下三段。

§3交互规约（磁性的具体定义）

  • 吸附半径：指针距插槽中心 ≤ 90px 时插槽激活；同时命中多个取最近。激活插槽从 0 宽度动画张开到节点宽（160ms ease），两侧节点自然让位——"链条为你腾位置"。
  • 放下：松手落在激活插槽 → 插入/移动到该位置；落在其它任何地方 → 取消回弹。移动链上节点时，原位置以 25% 透明度占位，方向感不丢。
  • 移除：拖动链上节点时画布下缘出现虚线移除区，进入变实、松手删除；触发器节点无移除。
  • 类型拒绝：不兼容节点在库里即变暗不可拖（点按轻晃 + 原因提示）；因此画布上不存在"拖进来才发现不行"——拒绝发生在最早的一刻。链中段插入用同一规则按"该位置的当前类型"判定。
  • 键盘可达：节点获得焦点后 ←/→ 换位、Delete 移除、Enter 打开右栏配置——磁性拖拽是增强，不是唯一路径。
