# 预置工作流的使用边界

内置流程是业务模块的可复用实现；模板是用户主动创建和配置的起点。启用状态不代表输入、账号和目录已经就绪。

## 入口与兼容策略

- 获取流程由“获取资源”传入资源、链接和任务信息；下载结果流程由下载器传入受管理的下载结果。通用运行接口拒绝缺少业务上下文的启动。
- 帖子解析保留专用手动输入表单；文件清洗模板使用扫描节点中配置的目录。
- 旧的手动磁链流程不再为新安装自动创建，改由“外部下载后入库”模板提供。已有定义、引用和运行记录保留。
- 内置流程与用户工作流分别展示；模板目录展示用途、配置与产物。用户副本可以修改，内置定义可另存副本。

## 场景清单

### 文件清洗模板

- 使用场景：文件名含重复前后缀、空白或格式不统一，希望把一组规则保存后反复使用。
- 配置与启动：从扫描节点选择服务端可访问的根目录，并配置文件名操作规则；保存后先运行并检查预览。
- 最终效果：生成重命名计划，在运行记录里检查并应用。运行工作流本身不会直接修改文件名。

### 外部下载后入库模板（原手动磁链流程）

- 使用场景：磁力链接或网盘需要使用自己的下载器，下载完成后希望继续整理入库。
- 配置与启动：先配置待处理目录和库目录。创建此工作流后，在获取资源中选择它；按任务提示将该资源的完整文件放入指定目录。
- 最终效果：等待你提供文件，再移动到库目录并关联资源。保留文件层级，默认不解压，也不负责启动外部下载器。

### 分享内容与网盘

- 使用场景：手上有含下载链接的帖子或文字，文件需要通过网盘等方式自行下载。
- 配置与启动：在获取资源补充帖子链接或文字；配置帖子解析 AI、待处理目录和库目录。已解析并导入的链接无需再用 AI 提取。
- 最终效果：提取并选择链接，等待你下载并提供完整文件，再按需解压、移动入库并关联资源。
- 人工交付：接收链接、提取码和目标目录；提交该资源的文件组或目录。分卷一起交付，可以注明已自行解压。提交后恢复原来的运行。
- 解析得到解压方案时，解压节点按方案顺序执行每层改后缀和密码；方案不明确时暂停等待补充。帖子解析和获取资源共用购买阈值及最低保留金币规则。

### 直链下载并入库

- 使用场景：已经有可直接返回文件的 HTTP(S) 地址，希望服务端下载并入库。
- 配置与启动：在获取资源补充文件直链，并配置库目录。下载设置可调整并发连接等参数；普通网页或登录页面不是文件直链。
- 最终效果：服务端下载文件，按需解压后移动到库目录，并关联到待获取资源。

### 磁力链接下载并入库

- 使用场景：已经有磁力链接，希望 Bakabase 直接取得文件并入库。
- 配置与启动：在获取资源补充有效磁链，并配置库目录。使用内置 BT 引擎；网络需要能连接到提供该内容的节点。
- 最终效果：下载完整内容并保留目录层级，再移动入库并关联资源。默认不解压，完成后停止做种。

### BT 种子下载并入库

- 使用场景：已经有 .torrent 文件或种子文件的下载地址，希望下载其实际内容并入库。
- 配置与启动：在获取资源上传种子，或填写可访问的 HTTP(S) 种子地址；配置库目录。网络需要能连接到有效节点。
- 最终效果：下载种子描述的完整内容，保留层级后移动入库并关联资源。默认不解压，完成后停止做种。

### ExHentai 下载并入库

- 使用场景：已知待获取资源对应的 ExHentai 作品，希望使用站点下载器取得完整内容。
- 配置与启动：配置 ExHentai 账号与下载方式、库目录，在获取资源使用该作品的 ExHentai 来源。账号仍需具有访问该作品的权限。
- 最终效果：下载图片；若站点返回种子，则继续下载 BT 内容，最后移动入库并关联资源。

### 平台获取或关联已有文件

- 使用场景：资源已在关联的平台账号中，想取得平台文件或关联已经安装的目录。
- 配置与启动：先同步平台资源并配置对应账号/下载目录。Steam 安装需要服务端所在机器具有桌面 Steam 客户端；纯服务端可关联其能够访问的已安装目录。
- 最终效果：调用支持的平台获取方式，或检测已有安装目录，并原地关联到资源。平台目录不搬到库目录；效果取决于平台能力。

### 本地目录入库

- 使用场景：资源文件已经下载到服务端可访问的文件夹，还未关联到待获取资源。
- 配置与启动：先配置目标库目录。从获取资源启动后，再按提示选择源文件夹；源目录不需要提前固定在工作流里。
- 最终效果：将选中的文件夹内容移动到库目录，并关联到资源。原位置会改变；这不是原地扫描。

### 下载种子内容

- 使用场景：独立 ExHentai 下载任务取得了种子，希望继续下载种子内的实际文件。
- 配置与启动：在下载器的 ExHentai 设置 → 下载结果后续处理选择此流程，再创建下载任务。输入由下载器提供，无需手动填写结果 ID。
- 最终效果：通过内置 BT 引擎下载到该下载结果目录。只取得文件，不创建资源或入库；如需入库，可创建扩展工作流。

### 帖子解析

- 使用场景：希望从帖子链接或粘贴的正文里整理下载地址和密码，先检查结果再决定下一步。
- 配置与启动：在帖子解析页添加内容，或在运行表单填写链接/正文；需登录的网页另需站点配置，也可直接粘贴正文。读取与保存快照先执行，未配置 AI 时在后续阶段等待配置。
- 购买：SoulPlus 自动购买单项阈值与最低保留金币均默认 0。存在未购买内容时，先分析失效/补档反馈；未发现失效或已有补档才尝试购买阈值内且余额允许的项目。未知价格、未知余额、疑似失效或超限内容等待人工处理。需要人工决定时，前往原帖查看价格和内容后自行购买，再点击“购买后刷新解析”重新获取；解析页不再提供直接购买按钮。
- 最终效果：输出标题、下载链接、提取码、链接检测状态和有序文件处理方案，可查看、复制或导出。未解锁完时显示部分结果并等待，不能作为完整成功导入。链接检测不支持或无法确认时标记未知。
- 快照保留第一页主题和带楼层信息的回复；失效判断仅针对已抓取范围。失败原因可展开，重试复用已完成阶段。新任务使用 v2 内置定义，原有工作流定义及历史运行保留。

### 按文件处理方案处理本地文件

- 使用场景：网盘已手动下载，或希望把同一份解压规则用于一个目录内的多个压缩包/分卷组。
- 配置与启动：手动选择服务端可访问的目录、可选文件清单和已保存的解压方案；也可在帖子结果中给选中的下载资源绑定本地目录。一个资源绑定启动一次独立运行，多资源批量入口为每个绑定分别启动。
- 最终效果：复用已有解压服务，按结构化指令顺序改后缀、重命名、移动到相对目录、使用对应密码解压。原件保留；执行器在独立工作目录保存输入、步骤进度和最终产物，重试不重复已完成的操作。无需解压的方案也只交付所选文件。
- 人工环节：密码错误、方案未知或文件选择无法匹配时暂停，允许补充密码、修改方案，或确认已自行处理。恢复沿用同一运行。默认预置停在文件处理结果；入库是可选的后续节点。
- 方案契约：`requirement` 为 `required`、`notRequired` 或 `unknown`；`steps` 按顺序包含 `id`、`op`、`input`、可选 `selector`，以及 `extension` 或 `password`。允许的操作为 `renameExtension`、`renameFile`（`targetName`）、`moveFile`（`targetDirectory`）和 `extractArchive`，`input` 引用 `download` 或前面步骤的 ID。重命名仅接受文件名，移动仅接受本次产物内的相对目录；禁止越界和覆盖。方案随下载链接持久化和导出，人工下载器与自动下载器交付相同的文件绑定即可复用后续节点。
